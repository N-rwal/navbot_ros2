# navbot_ros2

ROS2 Jazzy workspace for an omniwheel navigation robot.

## Packages

- stm32_omni_driver
- ld06

## Hardware

- Orange Pi Zero 2W
- STM32 motor controller
- LD06 LiDAR
- 4-wheel omni chassis

### Install
	```bash
	git clone --recurse-submodules git@github.com:N-rwal/navbot_ros2.git
	```
